# Temperature Converter in Java

A simple Java-based Temperature Converter that allows users to convert temperature values between **Celsius, Fahrenheit, and Kelvin** using standard conversion formulas.

## 📌 Features

* Convert Celsius to Fahrenheit
* Convert Fahrenheit to Celsius
* Convert Celsius to Kelvin
* Convert Kelvin to Celsius
* Convert Fahrenheit to Kelvin
* Convert Kelvin to Fahrenheit
* Simple and interactive user interface
* Accurate temperature conversion using standard formulas
* Easy-to-use menu-driven program

## 🛠️ Technologies Used

* **Java**
* **Object-Oriented Programming (OOP)**
* **Conditional Statements**
* **Methods**
* **Scanner Class**

## 🌡️ Conversion Formulas

| Conversion           | Formula                   |
| -------------------- | ------------------------- |
| Celsius → Fahrenheit | `(C × 9/5) + 32`          |
| Fahrenheit → Celsius | `(F − 32) × 5/9`          |
| Celsius → Kelvin     | `C + 273.15`              |
| Kelvin → Celsius     | `K − 273.15`              |
| Fahrenheit → Kelvin  | `(F − 32) × 5/9 + 273.15` |
| Kelvin → Fahrenheit  | `(K − 273.15) × 9/5 + 32` |

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Temperature-Converter-in-Java.git
```

2. Open the project in any Java-supported IDE such as **VS Code, IntelliJ IDEA, or Eclipse**.

3. Compile the Java program:

```bash
javac TemperatureConverter.java
```

4. Run the program:

```bash
java TemperatureConverter
```

5. Select the desired conversion option and enter the temperature value.
